What about OpenSCAD code?

Parametric .scad code needs compiling to a mesh. The included make_viewer.py helper accepts OpenSCAD files or pasted code and automatically runs the OpenSCAD command-line compiler, then generates a ready-to-view HTML file. The browser itself cannot compile arbitrary OpenSCAD source.
